## 지금까지의 결론 3가지
1. **Q1:** 논문 모델을 그대로 쓰면 실제 Windows 통화에서는 맞지 않는다. 직접 수집한 데이터로 재학습해야 한다.
2. **Q2:** 패킷만으로는 기기 원인이 보이지 않지만, OS 지표(CPU, 디코드 시간)를 더하면 구분할 신호가 있다.
3. **Q3:** 모니터는 가볍다 (CPU 약 1.3%).

**한계:** 모두 통화 1건씩의 파일럿이라 통계적 주장은 W3–W5에서 반복 수집한 뒤에 할 수 있다.
