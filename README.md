# cse310_MCQM
Multi-layer Call Quality Monitor (MCQM): real-time QoE estimation for desktop video calls (Google Meet and Microsoft Teams web clients in Chrome on Windows) from packet headers and OS metrics, with network-vs-device (CPU) cause diagnosis and post-action recovery verification, shown on a web dashboard and a mini widget. Built on noise-lab/vcaml (IMC'23). SUNY Korea CSE310 Final.
