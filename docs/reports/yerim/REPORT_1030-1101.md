## 제안 (실행하지 않음)
- **위젯 재오픈 시 그래프 깨짐 (B1)**: `scripts/widget_proxy.html` 45–49행에서 `#box`(캔버스 포함)를 PiP 문서로 옮기기만 하고, PiP가 닫힐 때(`pagehide`) 원래 문서로 되돌리는 코드가 없음. "Back to tab"이나 닫기 후 다시 열면 닫힌 문서에 붙었던 캔버스가 다시 옮겨져 깨졌을 가능성이 있음 [가설, 미검증]. 고치려면 `win.addEventListener("pagehide", …)`에서 `#box`를 원래 부모로 되돌리는 방법이 후보. 이번 작업에서는 수정하지 않았음.
  - **임시 수정본으로 검증됨**: repo 밖 `%TEMP%\mcqm_yerim\fix\widget_fix.html`에서 위 `pagehide` 핸들러만 추가(원본 대비 3줄: `const home = $("box").parentNode;` + `win.addEventListener("pagehide", () => home.append($("box")));`)하고 Back to tab 후 재오픈해 그래프가 정상 표시됨(사용자 확인). 원인 가설 확정. Windows Chrome 156 기준.
- `dummy_stream.py`는 직접 구현한 WebSocket이라 `websockets` 패키지로 만든 클라이언트는 쓸 수 없었음. 대시보드가 붙을 때는 표준 브라우저 WebSocket을 쓰면 됨.
- 브랜치가 `origin/main`을 추적 중이므로 push할 때 `git push -u origin web/yerim-verify`로 추적 대상을 바꿀 것.
