# T1 — pilot_live capture → capture/tshark_live.py
목표: `scripts/pilot_live.py`의 실시간 캡처 경로(tshark_path, load_models, OsSampler, parse, capture)를 `capture/tshark_live.py`로 옮겨 W2 이후 서버(FastAPI WS)가 import해서 쓸 수 있게 한다.

요구
1. `capture/tshark_live.py`(모듈, `capture/__init__.py` 필요하면 추가)에 위 함수/클래스를 둔다. 동작·출력 파일(`data/pilot/<name>_pkts|est|os.csv`) 형식은 **불변**.
2. tshark 서브프로세스 없이도 테스트할 수 있게, 라인 스트림(iterable of str) → 추정 행을 처리하는 부분을 분리한다 (예: `process_lines(lines, ...)` 가 emit 콜백/제너레이터로 1초 추정을 낸다). tshark 실행부는 얇게 유지.
3. `scripts/pilot_live.py`는 `compare`·`ifaces`·CLI(`main`)만 남기고 `capture`는 새 모듈을 호출. `scripts/overhead_ab.py`(`from pilot_live import OUT, OsSampler`)와 `scripts/cpu_load.py` 명령이 깨지지 않게 import 경로/문서 수정. 기존 CLI 호출(`pilot_live.py capture ...`)은 그대로 동작.
4. `tests/test_tshark_live.py` 추가: `docs/schema/sample.jsonl`이나 합성 라인으로 `parse()`와 라인 스트림 처리(가짜 모델/짧은 스트림)를 검증. 실제 tshark/네트워크/data/ 접근 없이 통과해야 한다.
5. `docs/COMMANDS.md`에 새 진입점(`uv run python -m capture.tshark_live ...` 또는 기존 CLI 유지 방식) 한 줄 반영.
6. `uv run --no-sync pytest tests/ -q` 전체 통과 (기준: 43 passed).

완료 기준 = 위 1~6 충족 + 추가 의존성 없음 + dashboard/·vcaml/ 변경 없음.
